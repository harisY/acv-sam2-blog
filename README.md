# Dari “Klik Objeknya” ke “Sebut Namanya”: Perjalanan SAM 2 menuju SAM 3

Review paper **SAM 2** (ICLR 2025) dan **SAM 3**, tutorial praktik **SAM 2.1**, dan ide riset untuk tesis. Ditulis oleh Abdul Haris (S2 TI UNPAM) untuk mata kuliah Advanced Computer Vision.

**Baca tulisannya:** https://harisy.github.io/acv-sam2-blog/

## Isi repositori

| Path | Isi |
|---|---|
| `index.md` | Naskah tulisan (Jekyll, dipublikasikan lewat GitHub Pages) |
| `notebook/sam2_tutorial.ipynb` | Notebook tutorial SAM 2.1 (gambar dan video) |
| `assets/img/` | Diagram arsitektur dan hasil percobaan |

## Menjalankan tutorial

[![Buka di Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/harisY/acv-sam2-blog/blob/main/notebook/sam2_tutorial.ipynb)
